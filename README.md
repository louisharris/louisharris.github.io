# Personal GitHub Pages Website

This repository contains my personal website hosted on GitHub Pages. You can visit the live site at [https://louisharris.github.io](https://louisharris.github.io).

## Development

To test locally, you can use any static file server. For example, using Python:
```bash
python -m http.server
```

Then visit `http://localhost:8000` in your browser.

- `index.html`: Main landing page
